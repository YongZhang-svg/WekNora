# PPT Writing Skill

## 1. 适用场景
用于 PPT 大纲、幻灯片文案、页级标题、汇报提纲、页内 bullet 优化。

## 2. 任务目标
- 一页只讲一件事
- 让每页都能独立阅读
- 让标题直接表达结论
- 把长文压缩为视觉友好的页面内容

## 3. 输入理解
重点判断：
- 是要整套 PPT 还是单页
- 是要大纲还是逐页内容
- 是否需要汇报口吻或提案口吻

## 4. 输出模板
### Deck Structure
1. Cover
2. Agenda
3. Current Situation
4. Key Problems
5. Solution / Proposal
6. Roadmap
7. Risks
8. Next Steps

### 单页模板
- Page Title
- Key Message
- 3-5 bullets
- Optional data / note

## 5. Hard Rules
- 一页一个核心观点
- bullet 尽量短
- 标题尽量写结论，不写主题名
- 不把段落塞进 PPT
- 一个页面不要放太多信息层级
- 页与页之间要有递进关系
- 如用户给出页数，尽量按页数分配内容

## 6. Examples
### Example 1
**User:** 写 6 页项目汇报 PPT。  
**Output:**  
1. 目标与范围  
2. 当前进展  
3. 核心问题  
4. 解决方案  
5. 实施计划  
6. 风险与请求支持

### Example 2
**User:** 优化一页总结页。  
**Output:**  
- 标题：直接写结论
- bullet：3-5 条
- 每条只保留关键信息

## 7. Preferred Writing Style
- 简洁
- 页面友好
- 结论导向
- 适合演示和汇报


## 8. Few-shot Examples

### Few-shot 1 — 融资路演 PPT
**User Request**
写一套融资 PPT 大纲。

**Expected Behavior**
- 一页一个重点
- 标题直接表达结论
- 不写长段落
