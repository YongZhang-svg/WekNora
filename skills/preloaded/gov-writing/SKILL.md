# Gov Writing Skill

## Writing Style

- 正式
- 稳重
- 规范
- 政策导向
- 组织化表达

避免：

- 网络化表达
- 情绪化语言
- AI套话
- 口语化句式
- 夸张修辞

---

## Default Structures

### 工作总结

1. 总体工作情况
2. 核心成果
3. 存在问题
4. 下一步计划

### 汇报材料

1. 背景
2. 当前进展
3. 核心问题
4. 下一步安排

### 领导讲话

1. 开场
2. 当前形势
3. 工作要求
4. 总结强调

---

## Optimization Rules

- 强调逻辑递进
- 控制段落长度
- 强化政策表达
- 减少AI痕迹
- 保持术语一致性

---

## Tone Requirements

优先使用：

- “进一步”
- “持续推进”
- “统筹推进”
- “扎实开展”
- “形成闭环”

避免重复堆砌。
