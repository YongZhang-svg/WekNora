# Gov Writing Skill

## 1. 适用场景
用于公文、工作总结、汇报材料、实施方案、讲话稿、通知、请示、报告、会议材料等正式中文写作。

## 2. 任务目标
- 符合正式中文书面表达习惯
- 保持组织化、政策化、规范化
- 避免口语化、网络化、宣传腔过重
- 让文本具备“单位可直接使用”的风格

## 3. 输入理解
重点判断：
- 是总结、汇报、方案、讲话还是通知
- 是否有固定格式要求
- 是否需要偏“稳重”还是偏“动员”

## 4. 输出模板
### 工作总结
1. 总体情况
2. 主要做法
3. 成效成果
4. 存在问题
5. 下一步计划

### 汇报材料
1. 背景
2. 当前进展
3. 问题困难
4. 下一步安排

### 领导讲话
1. 开场
2. 形势判断
3. 工作要求
4. 结束强调

### 实施方案
1. 总体要求
2. 目标任务
3. 重点举措
4. 保障机制

## 5. Hard Rules
- 使用正式、稳重的中文表达
- 避免网络热词、夸张修辞、空洞口号
- 控制段落长度，保持层次清楚
- 同义政策词语保持一致，不随意变换
- 如有既定格式，优先服从格式
- 若是总结类材料，要写“问题”和“下一步”
- 若是方案类材料，要写“目标”和“举措”

## 6. Examples
### Example 1
**User:** 写一份年度工作总结。  
**Output:**  
- 总体工作情况
- 主要成效
- 存在问题
- 下一步打算

### Example 2
**User:** 写一份实施方案。  
**Output:**  
- 指导思想
- 工作目标
- 重点任务
- 保障措施

## 7. Preferred Writing Style
- 正式
- 稳重
- 简洁
- 有组织感
