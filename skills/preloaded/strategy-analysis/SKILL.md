# Strategy Analysis Skill

## 1. 适用场景
用于趋势判断、市场进入、竞争格局、能力地图、业务策略、资源配置和方案选择。

## 2. 任务目标
- 找到真正的判断点
- 用单一主框架组织分析
- 输出可行动的策略建议
- 避免“把所有框架都套一遍”

## 3. 输入理解
判断用户是否在问：
- 趋势是什么
- 竞争态势如何
- 应该怎么选
- 如何布局资源
- 哪些机会值得优先做

## 4. 输出模板
### 标准模板
1. 结论
2. 分析框架
3. 关键观察
4. 机会 / 风险
5. 策略建议
6. 执行优先级

### 咨询风格模板
1. Core Answer
2. Why it matters
3. Key evidence
4. Implications
5. Recommended actions

## 5. Hard Rules
- 一次只选一个主框架，除非用户明确要求多框架
- 结论必须能落到动作
- 风险和机会必须分开写
- 避免“泛泛而谈的行业判断”
- 避免把结论写成口号
- 若证据不足，说明这是判断而非事实

## 6. Examples
### Example 1
**User:** 分析某赛道未来两年的机会。  
**Output:**  
- 结论：增长窗口存在，但竞争会快速加剧  
- 关键驱动：需求、供给、政策、成本  
- 风险：同质化、获客成本、合规  
- 建议：先切细分场景，再扩张

### Example 2
**User:** 做竞品分析。  
**Output:**  
- 维度：定位、功能、价格、渠道、壁垒  
- 结论：谁强、强在哪、弱在哪  
- 建议：我们该避开什么、放大什么

## 7. Preferred Writing Style
- 咨询风格
- 高管可读
- 观点明确
- 证据驱动


## 8. Few-shot Examples

### Few-shot 1 — 市场进入分析
**User Request**
分析进入 AI Coding 市场的机会。

**Expected Behavior**
- 判断市场是否值得进入
- 拆竞争和差异化
- 给进入策略

**Preferred Structure**
- 市场判断
- 核心玩家
- 差异化机会
- 风险
- 建议
