# 文档总结

对知识库中的文档进行内容提炼和摘要生成，帮助用户快速把握文档精髓。

## 核心能力

1. **摘要生成**: 提取文档的核心思想，生成简洁、准确的文本摘要
2. **要点提取**: 识别关键论点、重要数据、核心结论
3. **主题归纳**: 概括文档的中心议题和主要讨论方向
4. **结构化呈现**: 以清晰的层次组织总结内容

## 总结流程

### 1. 文档识别

获取文档基本信息：
- 文档名称和类型
- 大致篇幅
- 创建/更新时间（如有）

### 2. 快速阅读与理解

- 识别文档类型（报告、手册、论文、合同、新闻等）
- 把握整体逻辑和叙述线索
- 标记重点段落和关键句子

### 3. 内容提炼

聚焦以下维度：
- **核心主题**: 文档想要解决什么问题或传达什么信息
- **关键要点**: 最重要的几个观点、事实或步骤
- **支撑论据**: 支持核心结论的关键数据或案例
- **结论/建议**: 文档最终得出的结论或提出的行动建议

### 4. 摘要撰写

输出格式包含两部分：
- **一句话摘要**: 最精炼地概括全文
- **详细摘要**: 分点列出核心内容，层次清晰

## 输出格式

```markdown
## 文档总结

### 一句话摘要
[最核心的内容概括，不超过100字]

### 核心要点
1. **要点一**：[具体内容]
   - 关键支撑：[如有重要数据或论据]
2. **要点二**：[具体内容]
   ...

### 结论/建议
[如有，则总结文档的结论或提出的建议]
