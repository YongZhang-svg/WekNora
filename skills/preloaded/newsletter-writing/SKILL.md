# Newsletter Writing Skill

## 1. 适用场景
用于周报、月报、内刊、团队同步、业务更新、项目简报、信息通讯。

## 2. 任务目标
- 让读者快速浏览就能抓住重点
- 保持信息鲜明、节奏轻快
- 兼顾概览与行动提示
- 避免像会议纪要那样过度细碎

## 3. 输入理解
重点判断：
- 是内部同步还是对外简报
- 是一段总览还是多板块更新
- 是否需要"本期重点"式结构

## 4. 输出格式要求（强制）
**必须输出 HTML 富文本格式，而非 Markdown**

输出内容必须使用标准 HTML 标签，确保 Word 完美解析：

### 标题层级
```html
<h1>主标题</h1>
<h2>二级标题</h2>
<h3>三级标题</h3>
```

### 字体样式
```html
<strong>加粗文本</strong> 或 <b>加粗文本</b>
<em>斜体文本</em> 或 <i>斜体文本</i>
```

### 列表格式
**无序列表（项目符号）**：
```html
<ul>
  <li>第一项内容</li>
  <li>第二项内容</li>
  <li>第三项内容</li>
</ul>
```

**有序列表（编号）**：
```html
<ol>
  <li>第一步内容</li>
  <li>第二步内容</li>
  <li>第三步内容</li>
</ol>
```

### 段落与分段
```html
<p>段落内容，使用 p 标签包裹</p>
<p>另一个段落</p>
```

**列表内的分段**：
```html
<ul>
  <li><strong>重点标题</strong>：详细说明内容</li>
  <li><strong>另一个重点</strong>：更多说明</li>
</ul>
```

## 5. Hard Rules
- **强制使用 HTML 标签，禁止使用 Markdown 语法**
- 控制篇幅，一屏能扫完尽量一屏能扫完
- 每条信息尽量短而明确
- 避免长篇背景和流水账
- 若内容过多，先做聚合再展开
- 尽量采用"重点—说明—动作"格式
- **HTML 格式要求**：
  - 所有标题必须使用 `<h1>`, `<h2>`, `<h3>` 标签
  - 加粗使用 `<strong>` 标签，斜体使用 `<em>` 标签
  - 列表必须使用 `<ul>`/`<ol>` + `<li>` 标签，不要使用数字或符号
  - 段落使用 `<p>` 标签包裹
  - 标签必须正确闭合，HTML 结构完整
  - 缩进使用 2 个空格，保持 HTML 代码可读性
  - 不要在列表项内使用 `<br>` 换行，应分多个 `<li>`
  - 避免使用内联样式（style 属性），使用语义化标签
